# Profile

A modern personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS. This project showcases a polished one-page experience with sections for your introduction, skills, projects, experience, and contact details.

## Overview

This portfolio is designed to be:

- Responsive and mobile-friendly
- Fast to load and easy to customize
- Clean and professional for showcasing work and experience
- Simple to run locally for development and preview

## Features

- Hero section with a strong first impression
- About and experience sections
- Skills and project highlights
- Contact section with a friendly call to action
- Smooth, modern styling powered by Tailwind CSS

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- React Toastify

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open your browser at:

```text
http://localhost:5173
```

## Available Scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint checks

## Project Structure

```text
src/
  components/   # Page sections such as Hero, About, Projects, Contact, and Footer
  App.tsx       # Main app entry point
  index.css     # Global styles and Tailwind setup
```

## Customization

You can personalize this portfolio by updating the content in the components under `src/components/` and adjusting the visual style in `src/index.css`.

If you want to make the site your own, replace the placeholder content with your own biography, projects, experience, and contact information.
